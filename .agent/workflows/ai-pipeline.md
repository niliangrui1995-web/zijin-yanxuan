## AI 与数据管道规则

1. **Prompt 不写死在代码里：** 长篇提示词必须放在独立文件（`prompts/` 目录或 `prompt_templates.py` 字典）中，通过变量调用，禁止硬编码在业务函数里。

2. **强制 JSON + 防御解析：** 调用大模型时，提示词和代码双重要求输出 JSON 格式。解析返回结果必须 `try...except` 捕获 `json.JSONDecodeError`，模型抽风时记录日志并跳过，不能崩溃。

3. **缓存优先，不重复花钱：** 抓取的原始数据第一时间存本地（SQLite / JSONL）。调用 AI 前先查本地库，同一条数据处理过就直接读结果，禁止重复调用 API 浪费资源。
