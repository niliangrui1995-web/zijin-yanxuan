## 界面构建

1. **用组件库别手写：** 禁止手写复杂 CSS。优先用成熟组件库（Element Plus / Ant Design / Tailwind CSS），直接调用现成组件。生成 UI 代码时必须填入占位数据（Mock Data），让我一运行就能看到完整效果。

2. **卡片化 + 网格对齐：** 信息块用卡片（Card）包裹，统一圆角和阴影。布局强制用 Grid 或 Flexbox，元素必须严格对齐。主色调保持干净（白/灰背景），除涨跌指标外禁止大面积刺眼颜色。

3. **信息层级分明：** 标题、正文、辅助信息（时间戳、来源）必须有明确的字号和颜色深浅区分。表格中数字列右对齐，文本列左对齐。

4. **防挤压：** 缩小窗口时界面不能重叠或变形，用基础媒体查询或栅格系统兜底。

## 用户体验

5. **加载不能白屏：** 数据加载时用骨架屏或加载动画，超过 3 秒显示"正在获取数据，请稍候..."。请求失败后台自动重试 1-2 次，不打断用户操作，不立刻弹报错。

6. **报错说人话 + 给出路：** 拦截原始英文报错，UI 上翻译成大白话（如"连接超时，请检查网络"）。报错旁边必须带【重新加载】或【返回】按钮，不能只有一行冷冰冰的提示。

7. **信息降噪：** 长文本默认折叠（显示前两行 + "展开阅读"）。核心数据放左上角/顶部（F型视觉引导）。自动提取关键标签（公司名、技术名词）用彩色 Tag 高亮。

8. **防误触 + 记住偏好：** 删除、清空、消耗配额等操作必须二次确认弹窗。用户的选项偏好（时间范围、布局设置）存入 LocalStorage，下次打开自动恢复。

9. **终端级数据视觉 (UI)：** 数字强制定宽（如 Monospace，保证上下对齐）；A股行情严格遵守国内“红涨绿跌”。默认支持暗黑模式（Dark Mode），深色背景用多级深灰（如 `#121212` / `#1e1e1e`）而非纯黑，缓解刺眼。

10. **AI 任务过程透明 (UX)：** 超过 5 秒的离线或 AI 请求，必须显示分步进度指示（如：等待 L1 数据 -> 调度 Opus -> 映射完成），或是流式打字机输出状态。严禁界面一动不动的“假死”干等。

11. **性能与重型数据体验 (UX)：** 当列表或表格数据行超过 50 条（如大批量抓取结果、研报源），强制使用**虚拟滚动（Virtual Scrolling）**以防爆内存卡顿。高频控制面板须支持常用键盘快捷键（如 Esc 关闭面板）。
