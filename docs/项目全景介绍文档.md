## 一、项目定位

VCP Hunter 是一款 **A 股量化选股桌面终端**，核心策略来自 Mark Minervini 的 **VCP（Volatility Contraction Pattern，波动率收缩形态）**，辅以 **RPS（Relative Price Strength，相对价格强度）排名矩阵**。

系统能够：
- 全市场扫描符合 VCP 形态的股票
- 盘中实时监控突破信号
- 用 AI（Kimi/Moonshot API）做个股利空利好分析
- 展示专业 K 线图并自动标注 VCP 区间

## 四、核心算法详解

### 4.1 VCP 形态检测算法

VCP 的核心思想是：**股价在上升趋势中经历多次波动收缩，振幅逐次减小，形成"紧缩点"后突破**。

#### 检测步骤（`engine.py` → `evaluate_conditions()`）:

1. **趋势确认**
   - 50 日均线向上倾斜（斜率 > 0.001）
   - 当前价格在 250 日均线之上（距离 > 10%）
   - MA25 > MA60 > MA120（多头排列）

2. **高点寻峰**
   - 回溯 130 天，每 15 天为一组，取每组最高价
   - 筛选达到区间 93% 水位线以上的价格点作为"峰"
   - 合并 15 天以内过近的峰
   - 要求至少 3 个有效峰，且首尾间距 ≥ 50 天

3. **振幅收缩验证**
   - 计算区间最高价到最低价的振幅
   - 振幅 ≤ 用户设定阈值（默认 45%）
   - 后续峰的回调深度应逐次减小（第3峰不能低于第1峰的 85%）

4. **均线粘合度**
   - 计算 MA25/MA60/MA120 的相对偏离度
   - 偏离 ≤ 5%（默认）视为"粘合"
   - 但要求粘合前曾有过 ≥ 10% 的发散（排除长期横盘股）

5. **波动率过滤**
   - ATR(10) / 收盘价 > 0.5%（排除僵尸股）
   - 20 日平均成交额 ≥ 8000 万（排除流动性不足的个股）

6. **综合评分**（满分 100）
   - RPS250 权重 25%
   - RPS120 权重 15%
   - MA 粘合度 20%
   - 振幅收缩程度 20%
   - MACD 金叉 10%
   - 多头排列 10%

### 4.2 RPS 相对强度排名

```
RPS = (该股票 N 日涨幅在全市场的排名 / 总股票数) × 100
```

| 周期 | 含义 | 权重 |
|------|------|------|
| RPS50 | 50 日相对强度 | 参考指标 |
| RPS120 | 120 日（半年）相对强度 | 入池条件之一 |
| RPS250 | 250 日（一年）相对强度 | 核心筛选条件（≥80） |

RPS 矩阵通过 `build_rps_matrix()` 预计算，存入 `_daily_rps_cache` 字典。

### 4.3 板块 RPS

`SectorManager` 解析通达信本地板块数据文件（`blockdata/block_zs.dat` 等），将股票映射到行业和概念板块，然后计算每个板块的 RPS 排名。用于筛选"处于强势板块中的个股"。

## 五、五大功能模块详解

### 功能1: VCP 区间扫描

**入口**: 左侧面板 → 选择日期范围 → 点击"开始扫描"
**线程**: `ScanWorker(QThread)`
**核心流程**:

```
用户选择起止日期
    ↓
如果首次运行: 从通达信 vipdoc 读取全市场代码 + 缓存日线数据
    ↓
build_rps_matrix(cache_data, start_date, end_date)
    ↓ 返回 {日期: {rps120:{...}, rps250:{...}}}
遍历每个交易日:
    ↓
    过滤 RPS250 ≥ 阈值 的股票
    ↓
    对每只股票调用 evaluate_conditions()
    ↓
    通过的加入结果列表，附带评分和元数据
    ↓
可选: 批量查市值 (batch_check_market_cap)
可选: 查板块RPS (SectorManager.check_sector_rps)
    ↓
结果显示到 table_scan 表格
自动保存到 scan_results_cache.json
```

**扫描结果表格（12 列）**:

| 列 | 数据来源 | 说明 |
|----|---------|------|
| 序号 | 自增 | 行号 |
| 代码 | VCPEngine | 6 位股票代码 |
| 触发日期 | evaluate_conditions | YYYY-MM-DD 格式 |
| 名称 | data_provider.code2name | 通过 vipdoc 解析 |
| 收盘价 | 日线数据 df.close | 触发日收盘价 |
| 评分 | evaluate_conditions 计算 | 0-100 分 |
| RPS 强度 | build_rps_matrix | RPS120/RPS250 组合 |
| 市值 | pytdx 实时查询 | 单位: 亿元 |
| 距突破 | evaluate_conditions | 收盘价离区间最高价的% |
| 突破状态 | evaluate_conditions | 放量突破/临近突破/假突破 |
| 区间振幅 | evaluate_conditions | 高低点价差/最高价 × 100% |
| 热点板块 | SectorManager | 所属行业+概念板块 RPS 排名 |

### 功能2: 盘中实时监控

**入口**: "盘中实时" Tab → 点击"启动监控"
**线程**: `RtScanWorker(QThread)`
**刷新间隔**: 用户可选 30/60/90/120 秒

**核心流程**:

```
首轮:
    如果无缓存池 → 调 precompute_ready_pool() 构建待突破池
        precompute_ready_pool 内部:
        1. 获取全市场数据 + 预计算/加载 RPS
        2. 对 RPS≥80 的股票执行 evaluate_conditions()
        3. 筛出满足条件的股票 → _ready_pool 字典

每轮循环:
    fetch_realtime_quotes_batch(_ready_pool.keys())
        ↓ 返回 {code: {open, high, low, close, volume, last_close}}
    对每只股票调 rt_quick_check(code, realtime_data)
        ↓ 检查: 是否收红 + 是否突破区间最高价
        ↓ 返回: 突破状态 (放量突破/临近突破/假突破...)
    信号去重: (code, breakout_status) 组合
    通过信号发 signal_found 信号到 UI 线程
    UI 追加到 table_rt 表格

收盘后 (15:05):
    自动停止监控
    保存当日信号到 rt_monitor_YYYY-MM-DD.pkl
```

**盘中监控表格（11 列）**:

| 列 | 数据来源 | 说明 |
|----|---------|------|
| 代码 | _ready_pool | 6 位代码 |
| 时间 | 信号触发时刻 | HH:MM:SS |
| 名称 | code2name | 股票名称 |
| 现价 | 实时报价 | 当前最新价 |
| 涨幅% | (现价-昨收)/昨收×100 | 标准涨跌幅算法 |
| 评分 | precompute 阶段计算 | VCP 形态评分 |
| RPS 强度 | 预算 RPS120/RPS250 | 相对强度排名 |
| 突破状态 | rt_quick_check | 放量突破/临近/假突破 |
| 市值 | pytdx 实时查 | 亿元 |
| 区间振幅 | precompute 阶段 | % |
| 热点板块 | SectorManager | 所属强势板块 |

### 功能4: AI 智能诊断

**入口**: 右键菜单 → "AI 智能诊断" / "本地技术报告" / 关注池批量诊断按钮
**AI 引擎**: Kimi/Moonshot API (`moonshot-v1-32k` 模型)

**两种诊断模式**:

#### 模式A: Kimi AI 诊断
```
构建 prompt:
    - 注入股票代码、名称、当前评分、VCP 形态描述
    - 要求 AI 搜索最新利空利好信息
    - 指定输出格式：立场(看多/看空/中性) + 分析 + 建议

调用 API:
    POST https://api.moonshot.cn/v1/chat/completions
    model: moonshot-v1-32k
    tools: web_search（联网搜索）

解析返回:
    提取 choices[0].message.content
    显示在侧边栏 AI 面板中
    缓存到 ai_diag_special.json 或 ai_diag_rt.json
```

#### 模式B: 本地技术报告
```
从缓存数据计算:
    - MACD 金叉/死叉状态
    - RSI 超买/超卖
    - 布林带位置
    - 均线多头/空头排列
    - 量价配合度
    - VCP 评分和形态描述

生成纯文本报告（不需要网络）
显示在侧边栏
```

**AI 面板**: 停靠在主窗口右侧的可折叠面板（`QTextEdit` 显示结果）

## 九、线程与并发模型

| 线程/组件 | 类型 | 用途 | 并发控制 |
|----------|------|------|---------|
| UI 主线程 | Qt Main Thread | 所有 UI 操作 | 所有 UI 更新必须通过 `QTimer.singleShot(0, ...)` 回到主线程 |
| ScanWorker | QThread | 区间扫描 | 单例，支持取消 |
| RtScanWorker | QThread | 盘中循环监控 | 单例，`_running` 标志控制 |
| 市值查询 | TdxHq_API 连接 | 每批80股查询 | 独立连接 |
| AI 批量诊断 | ThreadPoolExecutor(5) | 并发调 Kimi API | max_workers=5 |
| F5 预计算 | threading.Thread | 盘后重建缓存 | daemon 线程 |
| 数据同步 | ThreadPoolExecutor(8) | 多线程读本地文件 | `cache_lock` 保护 |
